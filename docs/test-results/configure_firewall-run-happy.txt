## B. Pattern used by verify_firewall matches an existing rule and rejects a missing one

$ LC_ALL=C sudo ufw status verbose | grep -cE '^22/tcp[[:space:]]+ALLOW'
1
$ LC_ALL=C sudo ufw status verbose | grep -cE '^122/tcp[[:space:]]+ALLOW'
0

## C. External check: allowed vs. not allowed ports

[host] $ timeout 3 bash -c '</dev/tcp/192.168.122.13/8080'; echo "exit=$?"
exit=124
[host] $ timeout 3 bash -c '</dev/tcp/192.168.122.13/443'; echo "exit=$?"
bash: connect: Connection refused
bash: line 1: /dev/tcp/192.168.122.13/443: Connection refused
exit=1
# 8080 is not in the rules: packets are dropped silently (timeout, 124).
# 443 is allowed but nothing listens: packet reaches the VM and is refused (1).
