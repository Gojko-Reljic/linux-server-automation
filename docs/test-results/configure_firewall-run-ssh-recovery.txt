# What this proves: the script restores management access on an already-active
# firewall (new SSH connections work again).
# What it does not prove: the order "allow before default deny". Here the
# default policy was already deny, so no lockout window could appear. That
# order is guaranteed by the sequence in main() (apply_rules, then
# default deny incoming, then enable), not by this test.
